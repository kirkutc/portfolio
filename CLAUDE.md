# Резюме Кирилла Куцобина (single-file сайт)

Один файл `index.html`: HTML + CSS + JS, без сборки. Деплой: GitHub Pages (ветка `main`, корень).
Дополнительные файлы в репозитории (`img.webp`, `me-cutout.webp`, `CleanShot…jpg`) страницей не используются.

## Структура страницы
1. `.intro` (340vh) + `.stage` (sticky) — первый экран по мотивам deuxhuithuit.com/en:
   - `.mosaic` из 7 колонок `.mcol` (data-i 0..6), карточки `.mcard.im-<имя>`; скриншоты работ встроены в CSS как base64 (`.im-cbt`, `.im-amb` и т.д.).
   - Центральная колонка содержит невидимый `.mspacer`; поверх него `.mhero` — карточка с именем (`h1#nameEl`), Lottie-фигура (`#lot`) и таглайн.
   - JS-блок `// ── INTRO MOSAIC` управляет всем от прогресса скролла `p` (0..1): зазор колонок растёт, у колонок своё смещение по Y, крайние гаснут, `.mhero` растёт до полного экрана (меняются width/height/radius/font-size, текст остаётся).
   - Верхнее меню (`.controls`, `.intro-bar`) скрыто, пока `body` без класса `menu-on` (включается при p > .62).
   - Раскладка картинок в мозаике подобрана так, чтобы одинаковые/одноцветные карточки не стояли рядом.
2. `.page.lf` — контент: контакты, «О себе», опыт (`.exp-row`), стек (`.sk-grid`), образование, языки. Строки в стиле «название раздела слева, содержимое справа».

## Правила
- Двуязычность: тексты в `data-ru` / `data-en`, переключатель `setLang()`; имя меняется через innerHTML `#nameEl`.
- Тема: токены в `:root` (тёмная) и `[data-theme="light"]` (по умолчанию светлая), выбор в localStorage (в try/catch).
- Дизайн: ориентир deuxhuithuit.com — белый фон, шрифт Hanken Grotesk, сиреневые пилюли (`--pill`), акцент `--accent`.
- Печать/PDF: мозаика скрыта, остаётся шапка с именем (`@media print`).
- Lottie подключается с cdnjs (`lottie-web 5.12.2`); без неё остаётся статичный круг. Анимация встроена как JSON в JS.
- Ссылки на kirkutc.ru и «Академия 5 Prism»/личный сайт в портфолио не ставить (их нет).
